# pong-game
This is a simple Pong-style game built in Python using Pygame.
You can play:
- Player vs Player
- Player vs AI
  
What You Need
- Python 3
- Pygame
  
Use the keyboard to control paddles:
 Player 1: W / S
 Player 2: ↑ / ↓
 First to 11 points (with 2-point lead) wins!
